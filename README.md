Re-former

Re-former is a Ruby on Rails project I built as part of The Odin Project's Forms Project.

The project focuses on building forms in Rails and understanding how form data is sent to a controller and used to create and update records.

Features
Create a new user
Submit user information through a form
Display users
Use Rails controllers to handle form submissions
Work with Rails routes and parameters
Practice building forms manually with HTML
